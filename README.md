# Excel-Project
Zomato Restaurant Expansion 
Analyzed Zomato restaurant data, identifying 5+ high-potential markets for expansion with lower competition, leading to strategic decision-making for new restaurant openings.
Evaluated restaurant distribution by price range, average voter count, and customer ratings, emphasizing local cuisines and optimal pricing strategies to enhance market penetration and profitability.
Skills Used: Microsoft Excel (pivot tables, array formulas, data visualization) for structured analysis and actionable recommendations.
